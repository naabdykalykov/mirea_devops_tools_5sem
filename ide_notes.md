# Git в VS Code vs терминал

## Плюсы работы с Git через VS Code

1. **Наглядный diff.** Изменения видно построчно (слева — старая версия, справа —
   новая), не нужно вчитываться в вывод `git diff`.
2. **Постадийное добавление (staging по строкам).** Можно закоммитить только часть
   изменений в файле — прямо кликом по нужному куску кода.
3. **Быстрые базовые операции.** commit, push, pull, переключение веток — в один
   клик из панели Source Control, без запоминания команд.
