# Мой хобби-проект

**Идея:** frontend-приложение «Дедлайн-борд» — доска со всеми лабораторными и
дедлайнами семестра: карточки предметов, фильтр по статусу (не начато / в работе /
сдано) и подсветка того, что горит на этой неделе.

**Технологии:** React + TypeScript, Vite, React Router, Tailwind CSS,
состояние — Zustand, данные пока в localStorage

**Статус:** идея
